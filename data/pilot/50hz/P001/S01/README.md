# P001 S01 — 50 Hz Pilot Session

This session was collected at approximately 50 Hz using the preliminary
collection protocol. The finalized dataset uses a 100 Hz sampling rate.

This session is retained because the recordings are usable for visualization,
pipeline testing, and comparison. It must not be included in final model
training, validation, or test sets unless a preprocessing experiment explicitly
accounts for the sampling-rate difference.

P001 must be recollected at 100 Hz before being included in the finalized
participant dataset.

Expected properties of this pilot session:

- Sampling rate: approximately 50 Hz
- Trial duration: 2 seconds
- Samples per trial: approximately 100
- Classes: six active gestures plus idle
- Trials per class: 10
